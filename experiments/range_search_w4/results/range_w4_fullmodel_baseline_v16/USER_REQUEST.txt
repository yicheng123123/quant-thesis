==================================================
七、Pure Range Search full-model semantics
==================================================

这是本轮最重要的设计问题。

当前 local method：

alpha ∈ {0.1,...,1.0}

每个 candidate：
完整 dynamic GPTQ semantics

search objective：
local output reconstruction MSE

需要设计 full-model sequential integration。

要求：

按真实 GPTQ sequential order：

对于每个 quantized Linear / row：

1.
接收当前 quantized-prefix calibration input

2.
对 alpha grid 做 pure search

3.
只使用 calibration/search loss
选择 alpha*

4.
使用该 alpha 对当前 row/group
完成最终 GPTQ quantization

5.
更新当前量化模型状态

6.
继续后续 module

即：

本轮 full-model method
必须使用真实 self-propagated quantized prefix，
不能重新退回 FP-input。
