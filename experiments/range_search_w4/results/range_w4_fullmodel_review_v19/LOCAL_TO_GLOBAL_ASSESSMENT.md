# 局部与模型级证据

`selected_alpha.csv` 重新逐行计算：304,128 行中 283,818 行在 search 局部输出 MSE 严格改善，20,310 行与 α=1 精确持平，平均相对局部收益 12.826748%。这只是在**search calibration** 上、且候选集合包含 α=1 的优化结果，不能外推为 held-out 或 PPL 保证。

同一冻结模型的正式评测中，WT2 test M2 相对 M1 的 PPL 下降 0.891748%，C4 validation 固定预算下降 0.904210%。因此本次支持“局部重建改善能够伴随模型级质量改善”的**存在性实例**。仅一个 checkpoint、一条 WT2 test 流和一条 C4 固定预算流，没有独立模型重复，也未建立局部收益幅度与 PPL 收益幅度的预测关系；不声称统计显著、跨模型泛化或普遍改善。M2/M1 都仍低于 FP16 的质量。
