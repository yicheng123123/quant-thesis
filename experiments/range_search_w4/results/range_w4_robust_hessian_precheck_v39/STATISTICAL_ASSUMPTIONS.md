# 统计对象、可用证据与缺口

## 首选对象：固定输入映射下的总体平均局部风险

本轮只能把“总体平均”定义为：来自预先指定同一文章分布的新完整文章，经**固定模型前缀**得到的局部 Linear 输入，文章内 token 平均的误差。不是完整语言模型风险/PPL。

令文章 a 的二阶矩 A_a=(1/T_a)Σ_t x_at x_atᵀ，目标 C*=E_article[A_a]；等长文章时 C_hat=(1/n)Σ_a A_a。需要保护的是 eᵀC*e，而ρ要覆盖 ||C*−C_hat||op。本轮 n=16 篇/候选bank，维度896或4864；32768 tokens 不等于32768个独立观察。

实际前缀为已训练/量化的 v18 M2 固定前缀，不是本輪重构造的 robust 前缀。v30 本身未证明其生成校准池与当前文章在统计意义上独立。候选亦由同一 search 的 H 产生。不能简单条件化为“独立样本＋固定输入映射＋固定10个假设”；这需要额外数据来源核查或包含训练/前缀自适应性的理论。

## 必要假设，当前没有自动成立的项

1. **文章独立或可控制的依赖**：同源重复、近重复、同主题簇和抽样顺序可能破坏 iid。文章内允许 token 任意相关，但独立数仍以文章计。需要事先明确目标分布及抽样机制。
2. **矩条件**：有限 E||x||²可使目标存在，却不足以给有限样本的可计算高概率谱范数界。方差型界还需文章级 E||A_a||op² 等条件；指数型界需已知/可控制的有界或尾部常数。看到有限最大值不等于知道总体支持上界。
3. **文章长度/权重**：现有截取2048且等权。若未来长度不同，文章平均风险 E[A] 与 token总体风险 E[T A]/E[T]不同；后者样本量是文章、含随机分母和长度权重，不能直接套用当前公式。改变权重会改变 C 的定义。
4. **固定映射/选择适应性**：固定模型参数条件下文章级 Gram 集中的统一谱界可同时覆盖所有 e，因而覆盖数据依赖候选；但若前缀也依赖本批文章，需固定独立前缀或控制映射本身的适应性。只把生成的10个候选当成事前固定类，没有该保证。
5. **多矩阵覆盖范围**：矩阵级δ和全流程共同δ不同；12个局部单位与168个Linear不能直接共享同一置信声明。此处只审计4行，不给整个Linear/模型的实测风险声明。

## 另外两个对象不能混用

- **未来单篇文章**：保护 eᵀA_new e，而不是 eᵀE[A]e。ρ需控制 ||A_new−C_hat||，包含不可约的文章间异质性；总体均值估计误差随n减小，不会自动消除单文章波动。
- **跨领域**：保护 C_target，需要来源/目标 shift 的外部约束或目标数据。源域 search 单独不能识别任意目标域的谱距离。可分解 sampling uncertainty＋domain shift，但后项本轮无估计依据。

文章偏差 ||A_a−C_hat|| 的经验分位数最多是已观察分布的描述；使用同批均值、n=16、重尾与自适应前缀问题都未解决。它不是总体均值的置信界，也不能直接宣称单篇预测覆盖率。若要使用预测/保序校准，需要明确交换性、中心训练与校准的关系、有限样本分位数及覆盖对象；本轮不补这种方案。

## 复用统计量能做什么

v30 `KAPPA_NORMALIZATION.csv` 有12个 search矩阵的 trace/κ、文章索引和 H/hash。其候选表有480组原直接分数和||e||²。足够验证目标归一化与下包络，不足以从中识别文章级谱波动或尾部常数。

tr(C)/d仅给尺度；谱范数偏差不是 trace偏差。保留原完整 H 的文件存在，也不代表它包含每篇文章 A_a。当前审核的统计表没有用于有效文章级置信半径的充分信息。本轮没有读取完整输入、反序列化 H、构建文章 Gram 或做大型特征分解。

## 规则决策

**本轮提出0个可执行ρ估计规则。统计建模未完成。**

既没有已核验的独立性/已知尾部常数，也没有可复用的文章级方差/谱偏差充分统计；把经验分位数或κ乘某常数改名为“置信ρ”没有依据。即便有形式成立的最坏支持界，若界极松、使所有单位趋向最小weight error，亦不构成值得运行的新规则。

可证伪的新内容须至少同时提出：明确风险对象、search-only冻结半径、覆盖/假设校验，以及它相对共同τ会在哪些matrix中改变选择的事前预测。这些尚未满足；不因已有held负结果选择另一半径，不扫描超参数，不启动新实验。
