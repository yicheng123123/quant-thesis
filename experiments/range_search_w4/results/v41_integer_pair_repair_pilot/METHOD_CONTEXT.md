# 本轮定位

固定网格修复、二次型增量、单点下降、双点搜索都不是本轮原创。本轮只检验 search 相关性筛选的配对图，在相同候选评价预算上限下是否胜过单坐标与随机配对。A/B 是受已有方法启发的受限版本，不能冒称官方完整复现。

[ReQuant](https://arxiv.org/html/2608.07019v1) 冻结继承的量化网格，通过离散损失变化及缓存统计修复整数赋值。论文还考虑 FP 与量化前缀输入不一致，采用坐标扫描与局部整数邻域。本轮使用相同的历史固定 M2-prefix 输入定义误差，未实现激活失配项，采用全候选贪心、±1 与固定预算。

[CDQuant](https://arxiv.org/html/2406.17542v3) 已提出贪心单坐标和随机块下降；随机块方法按轮划分坐标块并搜索合法码组合，也讨论组参数和 clipping 初始化。本轮冻结已有 bank 的尺度和零点，随机无向边在修复前固定、允许重叠，与相关性图边数相同；联合邻域限制为 ±1，并按实际 FP16 cast 网格差计算增量。

剩余被检验的差异：仅由 search C 的归一化绝对相关性，每列固定 top2，再对无向边去重。跨组配对按各坐标自己的固定 scale 评分。本文献核对范围有限，不宣称该筛选策略在所有已有文献中均未出现；本轮不预设论文创新成立。

局部缓存 MSE、旧文章、六个 Linear 的四个代表输出行构成探索性证据。局部 alpha1 不是正式 M1；没有独立模型传播、整模型或 PPL 证据。
